Tortuga

Un mini lenguaje de dibujo que muestra cómo se reconoce: AFD léxico, autómata de pila LL(1) y árbol de derivación.

Referencia del lenguaje
  • avanza N · retrocede N mueven la tortuga N pasos
  • derecha N · izquierda N giran N grados
  • sube · baja levantan o apoyan la pluma
  • color NOMBRE
  • repetir N [ ... ] repite el bloque N veces
